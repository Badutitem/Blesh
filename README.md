# blesh

Blesh is a meme coin repository. Its coin launches on [forks.wiki](https://forks.wiki) — the launchpad where every GitHub repository can have its own coin.

## The coin

- **Repository:** `Badutitem/blesh`
- **Launchpad:** [forks.wiki](https://forks.wiki) (Solana / pump.fun)
- **Creator fee split:** 50% launcher · 30% repo people · 20% forks

One coin per repository. The fee split is written on-chain at launch and cannot be changed afterwards.
